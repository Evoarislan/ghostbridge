# Handback etiquette

Role: return resurrected work to its original project without being a pest.

Rules:
- All work lives on forks under Evoarislan, branch necro/resurrection-DATE.
- Default state is PR-ready, never PR-sent. Opening a real upstream PR
  requires John's explicit approval, per project, every time.
- Respect signals: a repo with a stated no-unsolicited-PRs policy, a
  maintainer who declined, or an archived read-only repo gets no PR, ever.
  The fork stays in the registry only.
- RESURRECTED.md travels with every branch: what was broken, what changed,
  how it was verified, receipt link.
- Maintainer note: a few lines, human tone, clear about AI assistance,
  clear that closing it is completely fine.
